# 🚀 v3.2.0 🚀

## Changelog

### 🎯 Core

- ✨ **Linux packages**: Install RoadRunner from an RPM on amd64 or arm64. Debian packages now use the name `roadrunner` across versions. See [RPM packages](https://github.com/roadrunner-server/roadrunner/pull/2460) and [Debian packages](https://github.com/roadrunner-server/roadrunner/pull/2467).
- ✨ **Composer package**: The v3 metapackage moved from `spiral/roadrunner` to `roadrunner/roadrunner`. See [PR #2431](https://github.com/roadrunner-server/roadrunner/pull/2431).

### 📦 `temporal` plugin

- ✨ **Activity resets**: An activity heartbeat reports a reset separately from a cancellation. With Temporal PHP SDK 2.19 or later, `Activity::heartbeat($progress)` throws `ActivityResetException` for a reset. See [Activity Heartbeats](../workflow/temporal.md#activity-heartbeats) and [PR #842](https://github.com/temporalio/roadrunner-temporal/pull/842).

### 📦 `jobs` plugin

- ✨ **Redis Streams**: Use `driver: redis` to run Jobs pipelines on Redis 8.0 or later. The driver supports delayed delivery and recovers unacknowledged jobs when a consumer stops. See [PR #2466](https://github.com/roadrunner-server/roadrunner/pull/2466).

### 📦 `kafka` driver

- ✨ **Partition ordering**: Set `consumer_options.pipelining_strategy` to `Serial` to finish a record and its retries before processing the next record from the same partition. Other partitions can run in parallel. See [PR #632](https://github.com/roadrunner-server/kafka/pull/632).

### 📦 `redis` driver

- ✨ **Native Redis commands**: Call `redis.IncrBy`, `redis.HSet`, `redis.ZAdd`, and other Redis commands over RPC with a named Redis KV connection. See [PR #250](https://github.com/roadrunner-server/redis/pull/250).

### 📦 `http` plugin

- ✨ **HTTP/3**: Configure `http.http3` to start the listener without the `-e` flag. See [PR #294](https://github.com/roadrunner-server/http/pull/294).

### 📦 `metrics` plugin

- ✨ **Prometheus metrics**: Set `metrics.prefix` and `metrics.labels` to add a name prefix and constant labels to metrics from RoadRunner plugins. Application, Go, and process metrics keep their names and labels. See [PR #208](https://github.com/roadrunner-server/metrics/pull/208).
